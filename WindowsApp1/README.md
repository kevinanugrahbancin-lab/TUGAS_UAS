# Sistem Perpustakaan-Develop


## Deskripsi
Aplikasi Sistem Perpustakaan berbasis Windows Forms.

## Branch Develop


Aplikasi Sistem Perpustakaan dibuat menggunakan Visual Basic .NET, SQL Server, dan RDLC Report.

## Fitur
- Login Sederhana
- CRUD Data Buku
- CRUD Data Peminjaman
- Pencarian Data
- Report Data Buku
- Report Data Peminjaman

## Cara Instalasi
1. Clone repository dari GitHub.
2. Buka project menggunakan Visual Studio 2019.
3. Restore NuGet Package.
4. Jalankan script SQL Server.
5. Jalankan aplikasi.

## Cara Menjalankan
Tekan tombol **Start** pada Visual Studio 2019.
