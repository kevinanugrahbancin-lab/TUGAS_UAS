# Sistem Perpustakaan-Develop
## Branch Develop
## Deskripsi

Aplikasi Sistem Perpustakaan dibuat menggunakan Visual Basic .NET, SQL Server, dan RDLC Report.

## Fitur
- Login Sederhana
- CRUD Data Buku
- CRUD Data Peminjaman
- Pencarian Data
- Report Data Buku
- Report Data Peminjaman

## Cara Instalasi
1. Clone repository dari GitHub.
2. Buka project menggunakan Visual Studio 2019.
3. Restore NuGet Package.
4. Jalankan script SQL Server.
5. Jalankan aplikasi.

## Cara Menjalankan
Tekan tombol **Start** pada Visual Studio 2019.

## Struktur Folder
- Form
- Report
- Database
- Packages

## Riwayat Commit
- Initial commit
- Menambahkan fitur Login
- Menambahkan fitur CRUD
- Menambahkan fitur Pencarian
- Merge seluruh fitur
- Release v1.0
## Pengembangan Fitur

- Branch `fitur-login` digunakan untuk implementasi login.
- Branch `fitur-crud` digunakan untuk implementasi fitur CRUD data.
